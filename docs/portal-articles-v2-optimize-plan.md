# 资讯列表页（/portal/articles）V2 优化方案

> 目标：在现有品牌渐变 Hero 基础上，增强层次感、内容密度与交互引导。

---

## 一、当前现状

页面已具备：
- 品牌色渐变 Hero（深绿 → 浅绿）+ 方格纹路
- 玻璃拟态搜索框（圆角 30px）
- 左侧标题 + 右侧搜索的 flex 布局
- pill 分类标签

---

## 二、优化计划

### Phase 1 — Hero 区域重构（布局 + 内容）

**当前结构：**
```
┌────────────────────────────────────────────┐
│ [渐变 Hero]                                │
│  资讯中心              [搜索框        搜索] │
│  绿色低碳产业资讯汇集地                     │
└────────────────────────────────────────────┘
```

**优化后结构：**
```
┌──────────────────────────────────────────────────────┐
│ [渐变 Hero — 保持现有高度 py-10 lg:py-14]            │
│  📰 资讯中心                                         │
│  聚焦绿色低碳，赋能产业发展                           │
│  #碳达峰  #双碳政策  #技术专利  #绿色金融             │
│                                            [搜索 🔍] │
│                                            [热门标签] │
├──────────────────────────────────────────────────────┤
│ [滚动快讯条] ◀ 最新政策解读已发布 | 双碳交流会6月15日 ▶ │
└──────────────────────────────────────────────────────┘
```

| 改动点 | 实现细节 |
|--------|---------|
| **高度** | 保持现有 `py-10 lg:py-14`，不再增加 |
| **标题区左对齐 + 图标** | 标题前加 `Newspaper` 线性图标，`text-4xl font-bold` |
| **副标题升级** | "绿色低碳产业资讯汇集地" → "**聚焦绿色低碳，赋能产业发展**" |
| **热门搜索标签** | 搜索框下方增加 4-5 个可点击标签：`#碳达峰`、`#双碳政策`、`#技术专利`、`#绿色金融`，点击后自动填充搜索框并搜索 |
| **搜索框缩短** | `max-w-md` → `max-w-sm`（约 384px），不再占据过大横向空间 |
| **搜索按钮图标化** | 文字"搜索" → 放大镜图标 `Search`，`rounded-full` 圆形按钮，渐变背景 |
| **网格对齐** | 整体使用 `grid grid-cols-1 lg:grid-cols-2 gap-8`，左侧标题区，右侧搜索区，垂直方向对齐 |

---

### Phase 2 — 滚动快讯条（Ticker）

在 Hero 底部、分类 pills 上方增加一条横向滚动快讯条：

```
┌────────────────────────────────────────────────────────┐
│ [浅绿底 bg-emerald-900/20]  backdrop-blur-sm          │
│  【最新】山东省碳达峰实施方案解读已发布               │
│  【通知】下一场双碳技术交流会将于6月15日举行          │
│  【政策】绿色低碳产业发展专项资金申报指南            │
└────────────────────────────────────────────────────────┘
```

**实现：**
- 背景：`bg-emerald-900/20 backdrop-blur-sm`（在渐变之上叠加半透明层）
- 文字：`text-sm text-white/90`
- 标签：`bg-white/20 rounded px-1.5 py-0.5 text-xs font-bold text-white`
- 动画：CSS `animate-marquee` 或简单水平滚动
- 内容：先硬编码 3-4 条示例数据，后续可接入 API

---

### Phase 3 — 背景与设计细节

| 元素 | 当前 | 优化后 |
|------|------|--------|
| **方格纹路** | 24px 网格 `opacity-[0.08]` | 保留，增加第二层微妙的径向渐变光晕（`radial-gradient` 圆形，中心亮边缘暗，极低透明度） |
| **搜索框投影** | 无 | `shadow-lg shadow-black/10`，增强脱离感 |
| **搜索按钮** | `bg-stone-800` 深灰 | `bg-gradient-to-r from-white/30 to-white/20 backdrop-blur-md border border-white/40` 玻璃按钮 + 白色图标 |
| **标题装饰** | 无 | `Newspaper` 图标 + 标题下方 `w-12 h-0.5 bg-white/30 rounded-full` 短分隔线 |

---

### Phase 4 — 响应式微调

| 断点 | 布局 |
|------|------|
| 移动端（< lg） | 标题在上，搜索框在下，热门标签横向滚动，`py-10` |
| 桌面端（≥ lg） | 左右两列 grid，`py-14` |
